Criando um array

Os colchetes [] depois do tipo avisam: "isto não é uma caixinha só, é uma fileira delas". Todas as caixinhas guardam o mesmo tipo de dado.

Tem dois jeitos de criar:

{ }Já com os valores, quando você sabe o que vai dentro. O tamanho é a quantidade de valores.
new int[5]Vazio, só com o tamanho, para preencher depois (por exemplo, com o Scanner). As caixinhas começam com 0 (em String, começam com null).
// jeito 1: já com os valores String[] frutas = {"manga", "caju", "uva"}; // jeito 2: vazio, com 4 posições double[] alturas = new double[4]; alturas[0] = 1.62; alturas[1] = 1.55;

Abrindo uma caixinha pelo índice

Igual às letras da String na aula 07, cada caixinha tem um índice que começa no 0. Para usar um valor, escreva o nome do array e o índice entre colchetes: frutas[0].

O frutas.length diz quantas caixinhas existem. Então a última é sempre frutas[frutas.length - 1]. Escolha um índice e veja o que acontece quando você passa do limite. 👀

0
String[] frutas = {"manga", "caju", "uva"}; System.out.println(frutas[0]);

length: com ou sem parênteses?

Essa confunde todo mundo! Na String, length() é um método e leva parênteses. No array, length é uma informação fixa e vai sem parênteses.

nome.length() // String: com parêntesesfrutas.length // array: sem parênteses

Mudando o que tem na caixinha

Dá para trocar o valor de uma posição a qualquer momento, usando o índice e o =, como numa variável normal.

O que não dá é mudar o tamanho. Um array criado com 3 posições terá 3 posições para sempre.

String[] frutas = {"manga", "caju", "uva"}; frutas[1] = "pitanga"; System.out.println(frutas[1]);
pitanga

Enchendo o array com o Scanner

Juntando tudo: um array vazio, um for e o Scanner. A cada volta, o i diz em qual caixinha o valor digitado vai entrar.

Depois de cheio, você pode percorrer o array em qualquer ordem. Lembra da contagem regressiva do foguete na aula 04? A mesma ideia serve para andar pelas caixinhas de trás para frente. 😉

int[] idades = new int[3]; for (int i = 0; i < idades.length; i++) { System.out.print("Idade da amiga " + (i + 1) + ": "); idades[i] = sc.nextInt(); }
Idade da amiga 1: 15 Idade da amiga 2: 16 Idade da amiga 3: 14

Repare no print sem ln: o cursor fica na mesma linha da pergunta, e a resposta aparece do lado.

Erros que toda iniciante comete (e tudo bem)

Passar do último índice

Num array de 3, os índices são 0, 1 e 2. O índice 3 quebra o programa com ArrayIndexOutOfBoundsException.

frutas[3]
frutas[frutas.length - 1]

Usar <= no for

Com <=, o loop tenta abrir uma caixinha a mais.

i <= frutas.length
i < frutas.length

Parênteses no length

No array, é sem parênteses.

frutas.length()
frutas.length

Misturar tipos

Todas as caixinhas têm o mesmo tipo.

int[] x = {1, "dois", 3};
int[] x = {1, 2, 3};

Desafio: o dia mais quente da semana 🌡️

Crie um array com as temperaturas dos 7 dias da semana, por exemplo {24, 29, 31, 27, 33, 30, 26}. Usando um for, descubra qual foi a maior temperatura e em qual dia ela aconteceu. Dica: guarde numa variável a maior temperatura que você achou até agora e compare com cada caixinha.

int[] temps = {24, 29, 31, 27, 33, 30, 26}; int maior = temps[0]; int dia = 0; for (int i = 1; i < temps.length; i++) { if (temps[i] > maior) { maior = temps[i]; dia = i; } } System.out.println("Maior: " + maior + "°C no dia " + (dia + 1));
Maior: 33°C no dia 5
