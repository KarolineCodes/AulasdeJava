Classe e objeto: qual a diferença?

Pense numa forma de biscoito de estrela. A forma não é um biscoito: ela só define o formato. Com ela você faz vários biscoitos, e cada um pode ter uma cobertura diferente.

Em Java é igual. A classe define quais informações existem (os atributos). O objeto é uma "coisa" de verdade, criada a partir da classe, com valores próprios.

Um arquivo para cada classe

Em Java, cada public class fica no seu próprio arquivo, e o nome do arquivo precisa ser igualzinho ao nome da classe, com a mesma letra maiúscula: Livro mora em Livro.java.

A classe que tem o main (por exemplo, Main.java) é onde o programa começa. É lá que você cria os objetos. Deixe os dois arquivos na mesma pasta para um enxergar o outro.

Lendo do teclado direto para o atributo

Lembra do Scanner da aula 05? Você não precisa guardar o valor numa variável solta antes. Ele pode ir direto para dentro do objeto.

E o bug do Enter fantasma continua valendo: número seguido de texto pede um sc.nextLine() sozinho no meio.

Livro livro = new Livro(); System.out.println("Quantas páginas?"); livro.paginas = sc.nextInt(); sc.nextLine(); // limpa o Enter System.out.println("Qual o título?"); livro.titulo = sc.nextLine();

Criando objetos dentro de um loop

Se o new estiver dentro do loop, cada volta cria um objeto novinho. A variável passa a apontar para o novo, e o anterior é descartado (por enquanto, já que ainda não aprendemos a guardar vários).

No exemplo, cada volta fabrica uma estrela com um brilho diferente.

for (int i = 1; i <= 3; i++) { Estrela e = new Estrela(); // nova a cada volta e.brilho = i * 10; System.out.println("Estrela " + i + ": brilho " + e.brilho); }
Estrela 1: brilho 10 Estrela 2: brilho 20 Estrela 3: brilho 30

Mostrando objetos com printf

Imagine que o Livro também tenha os atributos nota (double) e jaLi (boolean). O printf deixa a frase bem organizada. Cada marcador combina com um tipo de atributo, inclusive o %b, que é para boolean.

MarcadorTipoExemplo de valor
%sStringLuna
%dint3
%.1fdouble com 1 casa8.5
%bbooleantrue
System.out.printf("%s tem %d páginas. Nota: %.1f. Já li: %b\n", livro.titulo, livro.paginas, livro.nota, livro.jaLi);
Quarto de Despejo tem 200 páginas. Nota: 9.5. Já li: true

Esquecer o new

Sem o new, não existe objeto, só uma variável vazia.

Livro l; l.titulo = "Oi"; // erro
Livro l = new Livro(); l.titulo = "Oi";

Desafio: sua estante de livros 📚

Crie uma classe Livro com quatro atributos: titulo (String), paginas (int), nota (double) e jaLi (boolean). Na classe principal, crie dois livros diferentes, dê valores para eles e mostre cada um com printf, usando %s, %d, %.1f e %b.

Livro.java
public class Livro { String titulo; int paginas; double nota; boolean jaLi; }
Main.java
public class Main { public static void main(String[] args) { Livro livro1 = new Livro(); livro1.titulo = "Pequeno Príncipe"; livro1.paginas = 96; livro1.nota = 9.5; livro1.jaLi = true; Livro livro2 = new Livro(); livro2.titulo = "Torto Arado"; livro2.paginas = 264; livro2.nota = 10.0; livro2.jaLi = false; System.out.printf("%s | %d páginas | nota %.1f | já li: %b\n", livro1.titulo, livro1.paginas, livro1.nota, livro1.jaLi); System.out.printf("%s | %d páginas | nota %.1f | já li: %b\n", livro2.titulo, livro2.paginas, livro2.nota, livro2.jaLi); } }
