Como se cria uma variável

Toda variável em Java tem três partes, sempre nesta ordem: o tipo (que tipo de coisa ela guarda), o nome (a etiqueta da caixinha) e o valor (o que vai dentro).

O sinal = aqui não quer dizer "é igual". Ele quer dizer guarde isto aqui dentro. E no final vem o ponto e vírgula, que é o "ponto final" do Java.

int idade = 15;
intO tipo. Diz que a caixinha guarda um número inteiro.
idadeO nome. É assim que você vai chamar essa caixinha depois.
= 15O valor que vai ser guardado.
;Fim da instrução. Sem ele, o Java reclama.

Os tipos mais usados

💡 Nem todo número é número

Pergunte: "vou fazer conta com isso?". Uma matrícula como 00123 ou um CPF não entram em somas, e o zero da frente sumiria se virasse int. Por isso esses dados costumam ser guardados como String.

O padrão dos nomes: camelCase

Programadoras do mundo todo seguem o mesmo jeito de dar nome às variáveis. Chama camelCase porque as letras maiúsculas no meio parecem as corcovas de um camelo 🐪.

As regras: começa com letra minúscula, cada palavra nova começa com maiúscula, sem espaço, sem acento e sem começar com número. Para boolean, é comum começar com esta, tem ou eh, como estaVacinado ou temIrmaos.

Exemplos que seguem o padrão: corFavorita, anoFormatura, temBicicleta.

    Erros que toda iniciante comete (e tudo bem)

    string minúsculo

    O tipo de texto começa com S maiúsculo.

    string cor = "rosa";
    String cor = "rosa";

    Vírgula no decimal

    O Java é em inglês: decimal usa ponto.

    double preco = 9,90;
    double preco = 9.90;

    Número entre aspas

    Com aspas, vira texto e não dá para fazer conta.

    int irmaos = "2";
    int irmaos = 2;

    Esquecer o ponto e vírgula

    Toda instrução termina com ;.

    int ano = 2026
    int ano = 2026;
