Collections: as caixas que crescem

O Java tem um conjunto de estruturas prontas para guardar vários valores, chamado Collections. Elas moram no pacote java.util (o mesmo do Scanner). Diferente do array, elas crescem e diminuem sozinhas, sem tamanho fixo e sem precisar de contador.

Cada uma responde a uma pergunta diferente:

ColeçãoResponde à pergunta
List"o que está na posição 2?"
Map"qual valor está guardado nesta chave?"
Set"este valor já está aqui?"
Queue"quem é a próxima da fila?"

Nesta aula vamos ver a List (com a ArrayList) e o Map (com o HashMap), que são as mais usadas.

import java.util.ArrayList; import java.util.List; // vazia, para encher depois ArrayList<String> filmes = new ArrayList<>(); filmes.add("Moana"); filmes.add("Encanto"); System.out.println(filmes); // adicionando vários de uma vez filmes.addAll(List.of("Divertida Mente", "Valente"));

Lista não aceita int: use Integer

As coleções só guardam objetos, e não os tipos básicos (int, double, boolean). Para cada tipo básico, existe uma "embalagem" com nome de classe, que começa com letra maiúscula.

A boa notícia: depois de criar a lista, você usa os números normalmente. O Java embala e desembala sozinho.

💡 Cuidado com o remove

Quando você remove um item, todos os que estavam depois andam uma posição para trás. Se a lista era [pão, leite, uva] e você remove a posição 0, o leite vira a posição 0. Teste lá em cima e repare nos numerozinhos!

Percorrendo a lista

É igual ao array, só trocando length por size() e os colchetes por get(i).

Também existe o for-each ("para cada"), um jeito mais curto quando você não precisa da posição. Leia assim: "para cada String chamada f dentro de filmes".

// com posição for (int i = 0; i < filmes.size(); i++) { System.out.println((i + 1) + "º " + filmes.get(i)); } // for-each: sem posição for (String f : filmes) { System.out.println("🎬 " + f); }

HashMap: o dicionário do Java 📖

No HashMap, você não busca por posição, e sim por chave. Ele guarda pares: uma chave e um valor. É como um dicionário (procura a palavra, acha o significado) ou uma agenda (procura o nome, acha o telefone).

Regras importantes: a chave não se repete (se fizer put numa chave que já existe, o valor antigo é substituído), mas os valores podem se repetir. E o HashMap não guarda ordem.

Criando e percorrendo um HashMap

Na criação, você informa dois tipos: o da chave e o do valor. Para percorrer, use o keySet(), que devolve todas as chaves, e pegue o valor de cada uma com get.

Se você pedir uma chave que não existe, o get devolve null. O getOrDefault deixa você escolher o que devolver nesse caso.

import java.util.HashMap; HashMap<String, Integer> idades = new HashMap<>(); idades.put("Lia", 15); idades.put("Mel", 16); for (String nome : idades.keySet()) { System.out.println(nome + " tem " + idades.get(nome)); } System.out.println(idades.getOrDefault("Zoe", 0));
Lia tem 15 Mel tem 16 0

Aqui saiu na ordem em que colocamos, mas isso é sorte: com outras chaves a ordem pode mudar. No HashMap, nunca conte com a ordem!

Desafio: a votação do sabor de pizza 🍕

A turma votou no sabor de pizza da festa. Os votos estão numa ArrayList: ["queijo", "calabresa", "queijo", "frango", "queijo", "frango"]. Use um HashMap para contar quantos votos cada sabor teve e mostre o resultado. Dica: o getOrDefault(sabor, 0) ajuda a contar um sabor que ainda não apareceu.

import java.util.ArrayList; import java.util.HashMap; import java.util.List; public class Votacao { public static void main(String[] args) { ArrayList<String> votos = new ArrayList<>(List.of( "queijo", "calabresa", "queijo", "frango", "queijo", "frango")); HashMap<String, Integer> contagem = new HashMap<>(); for (String sabor : votos) { contagem.put(sabor, contagem.getOrDefault(sabor, 0) + 1); } for (String sabor : contagem.keySet()) { System.out.println(sabor + ": " + contagem.get(sabor) + " voto(s)"); } } }
frango: 2 voto(s) calabresa: 1 voto(s) queijo: 3 voto(s)

Repare que a ordem saiu diferente da ordem dos votos: é o HashMap sendo HashMap. Quer ir além? Descubra e mostre qual sabor ganhou a votação.
