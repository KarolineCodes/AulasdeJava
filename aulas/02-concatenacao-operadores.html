O Java também é calculadora.E sabe colar textos.

Com os operadores aritméticos o programa faz contas, e com o + ele junta textos numa frase. Mude os números e o tipo das variáveis para ver o resultado mudar.

int a = 17; int b = 5; System.out.println("Soma: " + (a + b)); System.out.println("Subtração: " + (a - b)); System.out.println("Multiplicação: " + (a * b)); System.out.println("Divisão: " + (a / b)); System.out.println("Resto: " + (a % b));

💡 Divisão de inteiros corta a parte decimal

Quando as duas variáveis são int, 7 / 2 dá 3, e não 3.5. O Java simplesmente joga fora o que vem depois da vírgula. Se você quer o resultado com decimais, use double. Teste lá em cima trocando o tipo!

E o %? Ele mostra o que sobrou: 7 % 2 dá 1. É muito útil para descobrir se um número é par (resto 0 ao dividir por 2) ou para transformar minutos em horas.

Concatenação: colando textos

Quando o + encontra um texto, ele não soma: ele cola. Assim dá para montar frases misturando texto fixo com o valor das variáveis.

Repare nos espaços dentro das aspas. Sem eles, as palavras ficam grudadas, tipo "Oi"+nome virando OiAna.

String nome = "Bia"; String comida = "brigadeiro"; System.out.println("Eu sou " + nome + " e amo " + comida + "!");

A pegadinha: o Java lê da esquerda para a direita

O Java resolve o + um passo de cada vez, da esquerda para a direita. Se o primeiro pedaço já é texto, tudo que vem depois vira texto também. Veja a diferença:

Sem parênteses

"Total: " + 5 + 3

Passo 1: "Total: " + 5 vira o texto "Total: 5".
Passo 2: "Total: 5" + 3 cola o 3 e vira "Total: 53".

Com parênteses

"Total: " + (5 + 3)

Os parênteses são resolvidos primeiro: 5 + 3 dá 8.
Depois o texto é colado: "Total: 8".

Moral da história: quando for fazer conta dentro de uma frase, coloque a conta entre parênteses.

Quem vem primeiro na conta

Igual na matemática da escola: *, / e % são feitos antes de + e -. Os parênteses furam a fila e são resolvidos antes de tudo.

Por isso, para calcular uma média, a soma precisa ficar entre parênteses. Sem eles, só a última nota seria dividida.

Sem parênteses

2 + 6 * 2 → 2 + 12 → 14

Com parênteses

(2 + 6) * 2 → 8 * 2 → 16

Comentários: bilhetes no código

Comentários são anotações que o Java ignora na hora de rodar. Servem para explicar o que o código faz, para você mesma ou para quem for ler depois.

Use // para comentar uma linha, ou /* e */ para comentar várias de uma vez.

// Isto é um comentário de uma linha int gatos = 3; // também pode vir no fim /* Isto é um comentário de várias linhas */

O espaço precisa estar dentro das aspas.

"Olá" + nome
"Olá " + nome

Média sem parênteses

A divisão acontece antes da soma.

n1 + n2 / 2
(n1 + n2) / 2

Esperar decimal de inteiros

Com int, a parte decimal some.

int x = 7 / 2; // 3
double x = 7.0 / 2; // 3.5

Esquecer as aspas no texto

Sem aspas, o Java acha que é o nome de uma variável.

System.out.println(Oi);
System.out.println("Oi");

Desafio: quanto tempo dura o filme?

Um filme tem 150 minutos. Crie uma variável com esse valor e mostre numa frase quantas horas inteiras ele tem e quantos minutos sobram. Dica: uma hora tem 60 minutos, e o / e o % vão te ajudar.

int duracao = 150; int horas = duracao / 60; // 2 int minutos = duracao % 60; // 30 System.out.println("O filme tem " + horas + "h e " + minutos + " minutos.");
O filme tem 2h e 30 minutos.
