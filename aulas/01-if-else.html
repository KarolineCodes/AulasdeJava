Todo programa precisa decidir.If e else ensinam como.

Você já faz isso toda manhã: se está chovendo, pega o guarda-chuva; senão, pega os óculos de sol. Em Java, essa decisão vira código. Aperte os botões e veja qual caminho o programa escolhe.

boolean estaChovendo = true; if (estaChovendo) { System.out.println("Levar guarda-chuva ☂️"); } else { System.out.println("Levar óculos de sol 😎"); }
Levar guarda-chuva ☂️

O que acabou de acontecer?

O computador segue o código de cima para baixo, linha por linha. Quando chega num if, ele para e faz uma pergunta que só tem duas respostas possíveis: verdadeiro (true) ou falso (false).

Se a resposta for verdadeira, ele entra no primeiro bloco de chaves. Se for falsa, pula esse bloco e entra no bloco do else. Nunca os dois ao mesmo tempo. É como uma bifurcação numa trilha: você escolhe um lado.

Em português: if quer dizer se, e else quer dizer senão.

As peças do if/else

ifA palavra que começa a pergunta. Sempre em letra minúscula.
( condição )A pergunta em si, sempre entre parênteses. Ela precisa dar true ou false.
{ ... }As chaves guardam o que deve acontecer se a condição for verdadeira.
else { ... }Opcional. É o plano B: roda só quando a condição é falsa.

Para montar a condição, você compara valores. Estes são os operadores de comparação do Java:

E quando existem mais de dois caminhos?

Às vezes a vida não é só "sim ou não". Uma nota pode significar aprovada, recuperação ou reprovada. Para isso existe o else if: ele faz uma nova pergunta quando a anterior deu falso.

O Java testa as condições na ordem em que aparecem e para na primeira verdadeira. Arraste a nota e observe qual linha acende.

8
Aprovada! 🎉
int nota = 8; if (nota >= 7) { System.out.println("Aprovada! 🎉"); } else if (nota >= 5) { System.out.println("Recuperação 📚"); } else { System.out.println("Bora estudar mais 💪"); }

Erros que toda iniciante comete (e tudo bem)

Errar faz parte de aprender a programar. Até programadoras experientes esbarram nestes:

Um igual em vez de dois

Um = guarda um valor. Dois == comparam.

if (idade = 15)
if (idade == 15)

Ponto e vírgula depois do if

O ; encerra o if na hora, e o bloco roda sempre.

if (nota > 7); {
if (nota > 7) {

Comparar textos com ==

Para String, use .equals().

if (nome == "Ana")
if (nome.equals("Ana"))

Esquecer de fechar as chaves

Cada { precisa do seu }. Alinhar o código ajuda a enxergar.

if (x > 0) { ... // cadê a chave?
if (x > 0) { ... }

Desafio: a catraca do cinema

Escreva um programa com uma variável idade. Se a idade for 14 ou mais, mostre "Pode entrar no filme 🍿". Se for menor, mostre "Esse filme é para maiores de 14". Tente sozinha antes de ver a resposta.

public class Cinema { public static void main(String[] args) { int idade = 13; if (idade >= 14) { System.out.println("Pode entrar no filme 🍿"); } else { System.out.println("Esse filme é para maiores de 14"); } } }

Quer ir além? Adicione uma variável boolean comResponsavel e deixe entrar quem tem menos de 14 se estiver acompanhada, usando ||.
