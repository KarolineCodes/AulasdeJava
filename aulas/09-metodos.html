Um método é uma maquininha com nome.Entra um valor, sai um resultado.

Você escreve o código uma vez, dá um nome a ele e chama quantas vezes quiser. Escolha uma maquininha, coloque um valor e aperte Chamar para ver o valor viajar do main até o método e voltar.

Por que criar métodos?

Imagine que você precisa calcular a média de uma aluna em 5 lugares diferentes do programa. Sem método, você copia e cola a mesma conta 5 vezes. E se descobrir um erro na conta, precisa consertar nos 5 lugares!

Com um método, a conta mora num lugar só, com um nome. Você só chama o nome. Isso deixa o programa organizado (cada método faz uma coisa) e sem repetição.

Em Java, "método" e "função" são a mesma coisa. E você já usa métodos desde a aula 01: o println é um método!

Sem método 😩

double m1 = (8 + 6) / 2.0; double m2 = (7 + 9) / 2.0; double m3 = (5 + 10) / 2.0;

Com método 😎

double m1 = media(8, 6); double m2 = media(7, 9); double m3 = media(5, 10);

As peças de um método

staticPor enquanto, sempre coloque. Ele deixa o main chamar o método direto, sem criar um objeto antes.
intO tipo de retorno: o que o método devolve. Se não devolve nada, use void.
quadradoO nome, em camelCase e de preferência um verbo ou uma pergunta: calcularMedia, ehPar.
(int n)Os parâmetros: variáveis que recebem os valores enviados na chamada. Pode ter nenhum, um ou vários.
public class Principal { public static void main(String[] args) { int r = quadrado(4); // chamando System.out.println(r); // 16 } static int quadrado(int n) { return n * n; } }

O método fica fora do main, mas dentro da classe. Nunca um método dentro do outro.

void ou return?

Todo método precisa dizer, antes do nome, se devolve alguma coisa.

void: só faz, não devolve 📢

Ele executa uma ação, como mostrar algo na tela, e acabou. Não dá para guardar o resultado numa variável.

static void avisar(String msg) { System.out.println("⚠️ " + msg); } avisar("Hora do intervalo!");

return: calcula e devolve 🎁

O return manda o valor de volta para quem chamou. O tipo do valor precisa combinar com o tipo declarado.

static double metade(double x) { return x / 2; } double m = metade(9); // 4.5

💡 Parâmetro ou argumento?

O parâmetro é a variável que fica nos parênteses da definição do método (double x). O argumento é o valor que você manda na chamada (9). Na hora da chamada, o argumento é copiado para dentro do parâmetro.

O que é esse static?

Lembra do Scanner? Para usar o nextInt(), você primeiro cria um objeto (sc) e depois chama sc.nextInt(). Esse método pertence ao objeto.

Um método static pertence à classe, não a um objeto. Por isso o main (que também é static) consegue chamá-lo direto, só pelo nome, sem criar nada antes.

Se esquecer o static, o Java reclama de "contexto estático" (non-static method cannot be referenced from a static context).

// método de objeto: precisa do sc int n = sc.nextInt(); // método static: chama direto int q = quadrado(5);

Sobrecarga: mesmo nome, parâmetros diferentes

A assinatura de um método é o nome junto com os tipos, a quantidade e a ordem dos parâmetros. Dois métodos podem ter o mesmo nome se as listas de parâmetros forem diferentes. Isso se chama sobrecarga (overloading).

O Java escolhe qual usar olhando os argumentos da chamada. Você já usa isso sem perceber: existem várias versões de println, uma para String, outra para int, outra para double...

Atenção: só mudar o tipo de retorno não vale. A assinatura não inclui o retorno.

static void desenhar(String s) { System.out.println(s); } static void desenhar(String s, int vezes) { for (int i = 0; i < vezes; i++) { System.out.print(s); } System.out.println(); } desenhar("🌷"); // versão 1 desenhar("🌷", 4); // versão 2

Um método pode chamar outro

Dentro de um método, você pode chamar outro método normalmente, só pelo nome. E se ele devolve boolean, o resultado pode ir direto dentro de um if.

Repare também que a variável t só existe dentro do método onde foi criada. Fora das chaves dele, ela não existe. Isso se chama escopo.

static boolean estaQuente(double graus) { return graus >= 28; } static void sugerirRoupa(double graus) { String t; if (estaQuente(graus)) { t = "vestido leve ☀️"; } else { t = "casaquinho 🧥"; } System.out.println("Vai de " + t); }

Erros que toda iniciante comete (e tudo bem)

Esquecer o static

Chamado direto do main, o método precisa de static.

int quadrado(int n) { ... }
static int quadrado(int n) { ... }

Método dentro do main

Métodos ficam lado a lado na classe, nunca um dentro do outro.

main(...) { static void oi() {...} }
main(...) { oi(); } static void oi() {...}

Esquecer o return

Se não é void, todo caminho precisa terminar com return.

static int dobro(int n) { int d = n * 2; }
static int dobro(int n) { return n * 2; }

Jogar o resultado fora

Chamar um método com retorno sem guardar ou mostrar o valor não mostra nada.

quadrado(5);
System.out.println(quadrado(5));

Desafio: o termômetro inteligente 🌡️

Crie um método paraFahrenheit(double celsius) que devolve a temperatura em Fahrenheit (a conta é celsius * 1.8 + 32). Depois crie um método descreverClima(double celsius) que devolve "Frio" abaixo de 18, "Agradável" até 27 e "Calor" acima disso. No main, mostre as duas informações para 30 graus com printf.

public class Termometro { public static void main(String[] args) { double c = 30; System.out.printf("%.1f°C = %.1f°F (%s)%n", c, paraFahrenheit(c), descreverClima(c)); } static double paraFahrenheit(double celsius) { return celsius * 1.8 + 32; } static String descreverClima(double celsius) { if (celsius < 18) { return "Frio"; } else if (celsius <= 27) { return "Agradável"; } return "Calor"; } }
30,0°C = 86,0°F (Calor)
